# NexVigil — Project Context

## Missão

Construir uma plataforma de Security Engineering reproduzível, segura e de baixo custo que permita praticar e demonstrar:

- Blue Team;
- Red Team controlado;
- Purple Team;
- Detection Engineering;
- Incident Response;
- DevSecOps;
- Cloud Security;
- AppSec;
- automação com Python;
- AI Security.

## Proposta

O NexVigil integra o ciclo:

**Attack → Detect → Investigate → Respond → Improve → Validate**

A plataforma começa local-first e evolui para cloud-ready/cloud-on-demand com Terraform.

## Restrições

- custo recorrente alvo: R$ 0 na fase inicial;
- sem dados reais;
- sem credenciais reais no repositório;
- attack range isolado;
- cloud apenas sob demanda quando necessário;
- IA não pode executar comandos arbitrários;
- ações críticas exigem aprovação humana;
- tudo que for ofensivo deve existir apenas no laboratório autorizado.

## Objetivo profissional

Transformar conhecimentos acadêmicos e laboratoriais em evidência prática de Security Engineering, permitindo demonstrar domínio técnico em entrevistas e portfólio.
